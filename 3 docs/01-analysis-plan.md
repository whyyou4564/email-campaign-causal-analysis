# 分析设计与指标口径

## 一、项目边界

分析单位为客户记录；结果观察窗口为邮件实验后两周。公开数据没有客户 ID、实验时间序列、分配日志、邮件打开记录、退订记录或长期结果。本项目使用来源所描述的随机分配设计，不声称凭借平衡检验证明随机性。

这是学习项目中固定的分析方案，不是事先注册的商业实验或研究方案。代码结构、分析和说明独立编写；仅使用公开原始数据。

## 二、业务问题与指标

| 问题 | 指标与分析 |
|---|---|
| 邮件是否增加购买 | 主要指标 conversion，按全部分配客户计算购买率 |
| 邮件是否增加访问 | 辅助指标 visit，不用点击/打开邮件替代访问 |
| 邮件是否增加收入 | 辅助指标 spend，包含零值的人均消费 |
| 两种邮件是否不同 | Mens − Womens；并分别与 No E-Mail 比较 |
| 谁产生更大增量 | 固定分群、交互检验、S/T/X-Learner |
| 预算有限怎么投放 | 验证集选策略，独立测试集评价增量与成本 |

分母始终按随机分配组统计。不能先筛选访问客户或购买客户再比较邮件效果，否则会条件化在实验后的变量上。

## 三、主要效应

处理 T=1 表示分配到邮件组，T=0 表示 No E-Mail。Y 为 conversion、visit 或 spend。估计目标为 ITT 平均效应 E[Y(1)-Y(0)]，不是“实际打开邮件者”的效果。

分别估计 Mens vs No、Womens vs No。合并邮件的效应指来源实验中的男装/女装邮件混合投放策略；改变内容比例或总是发送男装邮件，不能直接使用这个合并模型的评价结果。

## 四、统计推断

- 二元指标：两比例 z 检验，用于检验两个独立分配组的概率差；95% 差值区间采用 Newcombe-Wilson 方法。各组率的区间采用 Wilson 方法。样本量大且成功/失败计数足够时，z 近似适用。
- spend：Welch 均值检验与 Satterthwaite 区间，允许两组方差不同。消费零值多、分布右偏，另用 2,000 次组内 bootstrap 核对均值差的区间。业务目标是人均金额，因此不使用 Mann–Whitney 的秩差冒充均值差。
- 多重比较：4 个固定对比 × 3 个指标为 12 个检验，统一 Holm 控制家族错误率；另提供 Bonferroni 同时区间。普通 95% 区间只具逐项覆盖，不是全家族同时覆盖。
- SRM：以 1:1:1 作为计划比例假设，做卡方拟合优度检验，告警阈值 0.001。公开数据没有分配日志，比例假设及日志缺失必须说明。
- 随机化平衡：比较所有实验前变量的标准化均值差；分类变量逐类别转为指示变量。0.1 是常见检查参考线，不是随机实验是否成立的证明。
- 功效/样本量：以当前对照购买率作为后续实验的规划估计，研究 0.2、0.5、1.0 个百分点 MDE、80% 功效、1:1 与 2:1 分配。不使用观测效应计算“事后功效”来证明显著性。

## 五、为什么可以讨论因果

因果解释依赖：分配确实随机、处理定义一致、客户之间没有重要干扰、结果记录方式一致、没有分配后的系统性样本删除，并且每种处理有正概率。平衡/SRM 未发现异常只是支持性检查，不能代替原始分配日志。

ATE 不等于每个客户的个体因果效果：同一客户无法同时观测发邮件和不发邮件的结果。模型预测的是条件平均处理效应的近似。

## 六、协变量调整与异质性

Lin 完全交互线性回归使用中心化实验前协变量和 T×X，HC2 异方差稳健标准误，补充未调整的随机实验均值差。二元结果的线性概率系数是风险差；logistic 的 odds ratio 不能直接当作 ATE。

固定分群：newbie、历史 mens/womens 购买标记、recency 1–6/7–12 月、history 200 美元阈值、channel。分群均值差和 T×分群联合 Wald 检验均为探索分析，统一报告 BH FDR 修正。不能从“一组显著、另一组不显著”推断效应不同。历史买过男装/女装不是客户性别。

## 七、模型与策略评价

- 训练/验证/测试 = 60%/20%/20%，仅按三个实验组分层；随机种子固定。
- 预处理只在训练集拟合。特征白名单为 7 个实验前变量，history 取 log1p；history_segment 为冗余分箱，省略。禁止 visit、conversion、spend、segment 进入普通特征。
- 响应预测基线：logistic 模型预测购买概率，供投放排序比较。
- S-Learner：拟合一个含 T 的响应模型，分别设 T=1/0 预测后求差。
- T-Learner：分别拟合处理组和对照组响应模型，再预测求差。
- X-Learner：三折交叉拟合响应模型生成伪效应，分别回归两组伪效应，按处理概率组合。模型需要足够数据，交叉拟合不保证因果效果估计准确。
- 固定浅树与正则化参数；验证集选择增益模型以及默认成本场景中的投放比例，测试集不得调参。
- 主模型任务为 conversion。visit 作为辅助任务，不能用访问增益替代购买增益或利润收益。

## 八、评价指标的单位

本项目的原始增益曲线使用评估集实际分组比例作设计权重（不是拟合倾向评分）：
z_i = T_i Y_i/e − (1−T_i)Y_i/(1−e)。
按预测增益排序，前 k 人的 z 累加为预计增量人数。终点等于 N×两组均值差。横轴为覆盖比例。

raw AUUC = 对“增量人数/N”曲线积分，单位为每个候选客户的增量概率。减去随机投放直线得到 AUUC above random，不能将其误称为 scikit-uplift 的标准化 AUUC。本项目同时保存该库的标准化 Qini 和标准化 uplift AUC，以便核对不同定义。

Uplift@10%/30% 是入选人群中处理率 − 对照率；它不等于总体平均增量，更不等于模型预测分数均值。分位数组报告样本量、事件数和差值区间。相同分数的排序用不读取标签的固定随机数打散；库指标按其自身同分处理规则计算，两套曲线不要求逐点相同。

## 九、业务假设与不确定性

默认每封邮件成本 0.02 美元，每次增量购买的贡献利润假设为 30 美元，部署候选客户 10,000 人。这些是教学场景，不是数据中测得的实际成本、客单价或利润。真实人均 spend 的实验结果单独报告。

净收益 = 预计增量购买人数 × 假设贡献利润 − 邮件数量 × 假设成本。不将每封邮件收件人的所有购买都归因于邮件，不用收入替代利润，不把模型分数之和当作已验证的实际增量。

策略测试使用 masked outcome 两组均值差，等价按评估集实际分组比例 IPW；分母包含未入选客户的零值。随机策略既报告期望效果，也报告一次固定随机排序的离线估计。全量发送仅对应 100% 覆盖，不能在有限预算下作为可执行的同预算策略。

主要策略对比为锁定策略 vs 同预算随机期望策略。成对、分组 bootstrap 2,000 次给出差值区间；其余对比作为辅助。区间条件于已学习策略，不覆盖重新训练及模型选择的不确定性。测试集多个覆盖比例的曲线是描述性结果，不能再从中挑一个最好比例当作无偏结果。

敏感性：邮件成本 0.005/0.02/0.10/0.50 美元，贡献利润 10/30/60 美元。每个场景只在验证集重新选择比例，再在测试集评价。这个数据不支持长期收益、退订成本或跨企业推广保证。
